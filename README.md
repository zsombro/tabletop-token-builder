# Tabletop token builder

Create neat tokens for virtual tabletop tools like Roll20

Just find an image on the web, right click it, press "Copy image" and then press Ctrl+V/Cmd+V in the app.

Alternatively, you can drag multiple images from your computer straight into the app and edit them in bulk. Very useful for GMs who are preparing to run campaigns and need a lot of NPC tokens, but skip the hurdle of tediously editing them individually.
